FLOWBOARD v4 — Research-driven product direction

Competitive patterns (researched August 25, 2026)

MIRO
- Broad visual workspace: drawings, stickies, diagrams, documents/files, voting, timer, clustering, AI and a large template ecosystem.
- Templates are discoverable, categorized and previewable.
- Strategic warning: users also complain that growing feature density can make the product feel cluttered.

FIGJAM
- Excellent low-friction collaboration and clean interaction model.
- Hundreds of templates, voting, timer, Spotlight/facilitation, reactions, comments/audio and guest sessions.
- AI generates boards/diagrams and sorts/summarizes stickies.

MURAL
- Strongest differentiation is facilitation: timer, anonymous voting, private mode, summon/follow, facilitator locking, hide/reveal and laser pointer.
- Strong workshop methods and custom templates.

MICROSOFT WHITEBOARD
- Ink-first, approachable UI; collaborative cursors, lasso and templates.
- Standalone Windows/iOS/Android apps retire September 14, 2026, but Whiteboard remains available on the web and in Teams.
- Commercial boards are stored as .whiteboard files in OneDrive. Official end-user export is image; Microsoft also documents a PowerShell HTML export path.

V4 IMPLEMENTED
- Offline PDF export
- Focus mode has a visible Exit Focus button; Escape also exits
- Paste text or images with Ctrl/Cmd+V
- Drag/drop PNG/JPG/WebP images
- Imported images sit beneath ink, so users can annotate directly over them
- More visible, colorful, aligned template library
- Consistent SVG toolbar icons instead of emoji/generic glyphs
- Pen icon shows selected ink color
- Multi-board workspace and editable .flowboard export/import
- Locked owner product branding; customer branding controls removed

BRANDING STRATEGY
Keep your product logo and name visible. Let Team/Business customers set workspace accent colors, organization templates and logo-on-export, but keep product attribution. True white-label/OEM should be an expensive Enterprise option, if offered at all. This preserves your brand while still giving customers useful brand controls.

SIGN-ON / COLLABORATION
Add sign-on for owners and persistent collaborators, but do not force every guest participant to create an account. Recommended roles: Owner, Editor, Commenter, Viewer and time-limited Guest Session. Guest links can expire and optionally use passcodes/domain restrictions.

MICROSOFT WHITEBOARD MIGRATION
Do not market Microsoft Whiteboard as fully disappearing: Microsoft is retiring the standalone apps, while web/Teams remain. The opportunity is migration from standalone usage and legacy Azure boards.
Current FlowBoard path: Microsoft Whiteboard image export -> import into FlowBoard -> annotate over it.
Next migration paths: HTML export conversion, then direct .whiteboard conversion only after testing against real .whiteboard files and supported APIs.

MUST-HAVE NEXT FEATURES
1. Lasso/multi-select, resize, rotate, group, align/distribute, lock/layers
2. Connectors that snap to shapes; diagram auto-layout
3. Frames + presentation/spotlight + outline navigation
4. Anonymous voting / dot voting
5. Private brainstorm mode, then reveal
6. Facilitator “bring everyone to me”
7. Comments, @mentions, reactions and notifications
8. Realtime cursors/presence and account-backed cloud boards
9. Version history and named checkpoints
10. Search across boards for decisions/actions
11. PDF page import + annotation; PPTX/DOCX/CSV/SVG import
12. Team template publishing and template marketplace
13. AI clustering, summarization, diagram generation, decision extraction and action creation
14. Accessibility, keyboard navigation, stylus/mobile optimization
15. Offline-first sync, SSO/audit/retention for enterprise

PRODUCT MOAT
Build the workflow around: Idea -> Cluster -> Vote -> Decision -> Action -> Owner -> Due date -> Done.
The canvas should not end when the meeting ends. It should turn workshop output into accountable execution.
