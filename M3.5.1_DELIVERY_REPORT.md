# HuddleCanvas M3.5.1 Delivery Report

**Baseline:** `798dc2f` (`m3/hosted-alpha`)  
**Internal recovery commits:** `98ff737`, `cc5af7c`  
**Milestone:** Selection Move/Resize/Rotate/Lock Foundation  
**Decision:** Approved as an internal/private-alpha checkpoint; not approved for public release.

## Delivered

- Central command dispatcher for move, resize, rotate, lock, delete, and ink erasure.
- Atomic multi-object `object.transform` command with all-or-nothing validation.
- Finite and bounded positions and dimensions, normalized rotations, lock checks, and one generation increment per command.
- Single-object pointer resize and rotation controls with transient previews and one history transaction per completed gesture.
- Keyboard-equivalent size and ±15-degree rotation actions.
- Contextual lock/unlock behavior explicitly described as preventing accidental edits.
- 32px pointer targets and removal of nested interactive semantics.
- Expanded unit and Playwright scenarios for transforms, history, locking, persistence, and validation.
- ADR update documenting the transitional command boundary and remaining direct mutations.

## Verification still required

The browser tests could not execute in the restricted delivery environment because the Playwright Chromium binary was unavailable and its download was blocked/truncated. Before merging or deploying, GitHub Actions must show all three Chromium tests passing. Manual QA must also verify rotated resizing at normal zoom and at a zoomed level.

## Public-release blockers

- The API still accepts whole-board document saves; canonical commands and object locks are not yet server-authoritative.
- Canonical schema limits, legacy command bounds, request rate limiting, document/storage quotas, and version-retention controls require hardening.
- Remaining direct mutations (creation, duplication, content/style edits, and title typing) still need typed commands.
- Cross-browser, keyboard-only, accessibility, touch/stylus, conflict, offline, retry, and unload recovery evidence is incomplete.
- Pointer resize/rotation handles remain focusable but do not perform a keyboard action; equivalent toolbar controls exist, but focus behavior should be resolved before public release.
- Group transforms require a separate ADR defining world-space versus parent-space behavior.
- Major v8 parity work remains: images/annotation, groups, connectors, frames, templates, facilitation, export, comments, realtime, and guest access.

## Recommended application sequence

1. Apply `HuddleCanvas-M3.5.1-selection-transform-lock.patch` to a clean `m3/hosted-alpha` checkout at `798dc2f`.
2. Run `pnpm install --frozen-lockfile`.
3. Run `pnpm check`.
4. Run the full Playwright workflow in GitHub Actions.
5. Perform the manual rotated-resize check.
6. Merge only as an internal M3.5.1 checkpoint.
